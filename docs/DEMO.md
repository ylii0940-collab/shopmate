# ShopMate 三分钟演示

1. 首页输入“100美元以内，适合坐飞机的降噪耳机”。展示预算、特性与候选。
2. 追问“比较前两款”，展示同一批商品的价格、续航和重量。
3. 继续问“哪款续航更长”，展示上下文保留与参数来源。
4. 说“便宜一点”或“预算改成60美元”，展示条件更新与重新筛选。
5. 说“把第一款加入购物车”，先选择颜色，确认后加购。
6. 打开购物车，调整数量并进入结账交接预览，生成交接单。

简历可表述：独立实现面向国际电商消费者的流程式导购Agent，支持多语言需求抽取、上下文偏好合并、约束推荐、商品对比、规格确认和购物车交接；搭建自动化测试验证预算、库存、商品指代及结账核算。

说明数据为模拟，真实店铺、支付和推荐收益尚未验证；不要写成已经服务真实客户或提升真实转化。

## 搜索策略演示（约3分钟）

1. 打开“搜索策略”，使用默认出行耳机查询，看200→召回→过滤后→3的链路。指出缺货、超预算、类型不符分别在哪拦截。
2. 切换“策略对照”，对比A/B/C的Top3、排名变化和品牌数量；不要把品牌更多说成转化更高。
3. 展开权重调节，把预算权重降低，查看得分拆解和评估重新计算。点击恢复默认。
4. 进入离线评估和策略决策：比较当前三种策略得分，定位具体退化查询，提出预算中心78%假设的消融，而非直接声称新策略胜出。
5. 选择C并“应用到导购”，打开商品详情、选颜色、成功加购并去结账预览；返回行为漏斗，查看实际事件关联。
6. 说明下一阶段需独立标注和真实店铺随机实验，当前没有真实转化收益。

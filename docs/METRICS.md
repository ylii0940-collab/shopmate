# 搜索策略指标、归因与实验口径

## 离线评估

`dist/eval-data.mjs`定义140条固定查询，覆盖中英印尼语、US/UK/SG/ID、预算、特性、品牌、少结果、无结果与拼写归一。当前200件合成商品为封闭池；按固定规则给出0–3级判断，未列出记0。每次调整权重重新计算，不能改标注来让新策略获胜。

- nDCG@3：DCG=sum((2^grade−1)/log2(rank+1))，除以所有正相关标注的理想Top3 DCG。
- Precision@3：Top3相关商品数/3。展示不足3款仍以3为分母。
- 召回覆盖率：召回阶段命中的正相关商品数/全部已标注正相关商品数。
- 预期无结果样本不进入以上三个均值，单独评价是否正确返回空结果。
- 约束通过率：没有违规展示的查询/全部查询；需结合有无结果判断，防止空结果掩盖错误。
- 平均品牌数：所有样本Top3的不同品牌数量平均值，仅描述多样性。

这些是开发诊断指标。140条合成规则样本不足以证明策略优越性，未做显著性检验。`node scripts/evaluate.mjs`可复现默认权重报告。

## 浏览器行为

保留最近1000条事件。只统计当前保留窗口中有search_results根事件的导购操作，策略分析的试跑不计入。商品卡>=50%进入视口触发search_impression，同searchId+productId去重。打开详情或开始选颜色触发product_clicked，此处叫商品交互而非平台标准点击。

商品交互率=唯一已曝光商品交互数/唯一曝光商品数。漏斗按searchId去重：搜索→实际曝光→商品交互→成功加购→到达结账预览，逐级关联同一次搜索和商品。购物车保存来源，同商品同颜色多次加购合并时采用最后一次有效搜索来源。无法跨设备或恢复被截断事件。

快速返回率：已点击商品在10秒内关闭详情且未发生同来源加购的比例；没有停留防抖与反作弊，只是演示信号。无结果率=空productIds的搜索/搜索次数。未接入支付，不计算真实CVR/GMV。

## 线上实验计划（尚未执行）

目标是可靠地帮助用户完成选购，不是单纯增加DAU、聊天轮次或停留。主指标可选搜索会话到有效店铺结账的比例，支付接入后增加真实订单转化；护栏包含硬约束违规、无结果、延迟、退货投诉和长期回访。

按用户稳定随机分桶；A/B共用查询入口、商品价格和UI，在同时间窗运行。提前注册人群、MDE、样本量和观察期；检查分流比例、曝光去重与订单归因。分析总体和市场、品类、新老用户分层。主指标改善且护栏稳定再扩量；护栏恶化回滚；证据不足不宣称胜出。

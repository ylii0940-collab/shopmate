# 200件商品与多品类评估

保留原p1–p40，新增160件合成商品。头戴耳机32、耳塞32、音箱32、相机28、充电宝28、包袋24、桌灯24，共200件、7种商品类型。均为模拟数据，不接入真实交易。

同类候选覆盖基础、轻旅、优选、进阶系列；价格、品牌、评分、库存、1–9天配送、市场限制与属性各有差异。新增充电功率、相机视频规格、包袋升数、桌灯亮度，可在详情及比较表查看。未提供的旧商品字段不补造。当前搜索只识别已支持的品类、预算、品牌和标签，不承诺理解任意数值规格要求。

## 复现

- node scripts/expand-catalog.mjs：确定性生成新增商品，无网络数据和随机收益。
- node scripts/build-evaluation.mjs：按公开属性规则生成并冻结140条评估样本；不读取排序分、权重或策略结果。
- node scripts/evaluate.mjs：重算A/B/C结果。
- node --test tests/*.test.mjs：执行回归测试。
